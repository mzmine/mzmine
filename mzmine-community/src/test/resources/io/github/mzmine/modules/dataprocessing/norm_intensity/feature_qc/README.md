# Feature-QC reference fixture

`dunn_qc_rlsc_nonlinear.csv` is generated by `generate_dunn_qc_rlsc_fixture.py`, an independent
standard-library Python implementation of integer-neighborhood LOOCV, tricube local polynomial
fitting, bisquare reweighting, and natural-spline interpolation. It does not invoke the Java
implementation and does not establish R or qcrlscR equivalence.

`FeatureQcSmoothingTest` checks the selected degree, neighborhood, cross-validation error,
predictions and factors against that fixture. It also checks that fixed smoothing reproduces the
automatically selected curve when given the same span and degree, without calculating a LOOCV
score. Closed-form linear/quadratic cases, robustness, singular neighborhoods and cancellation
exercise the shared fitter. Pipeline tests cover per-batch QC means, injection order, conditioning-QC
exclusion, missingness thresholds, unsupported batches, boundaries and factor limits.

## QC-RLSC numerical-core benchmark

`FeatureQcSmoothingBenchmark` is an opt-in Java `main` benchmark. It uses a deterministic nonlinear
positive response, performs five warm-up fits and reports the mean of 20 complete automatic `fit`
calls with two robust iterations. The implementation caches coordinate neighbor order and uses
centered weighted moment solves with a QR fallback. Automatic smoothing evaluates the full
candidate/fold search; fixed smoothing skips it.

These numerical-core timings do not measure a whole feature-list normalization, batch grouping,
diagnostics, project persistence, UI work, or memory peak. The numerical checks do not substitute
for validation on representative analytical data.
