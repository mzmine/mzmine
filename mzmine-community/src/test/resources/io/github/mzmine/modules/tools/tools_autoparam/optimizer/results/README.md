# Auto-param benchmark evidence

These CSV files are the retained trajectories and summaries used by
`docs/implementation-notes/autoparam-optimizer-evaluation.md`. They include pilots of algorithms
that were later removed, so the decisions remain reproducible and are not based only on the prose
summary.

New benchmark runs write to `mzmine-community/build/autoparam-benchmarks` by default and should not
overwrite this evidence unless they intentionally reproduce the same documented campaign.
