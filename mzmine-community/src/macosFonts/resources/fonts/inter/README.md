# Bundled Inter fonts

Unmodified static OpenType faces from Inter 4.1.

Source: https://github.com/rsms/inter/releases/tag/v4.1
Archive: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

These resources are published in the optional `macos-fonts` artifact and are
included only in macOS application runtimes. `themes/fonts_macos.css` registers
the four faces through JavaFX and preserves the existing theme sizes and styles.
